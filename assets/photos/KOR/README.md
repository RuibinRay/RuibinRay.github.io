# Photos from South Korea

Make a folder here for each city or province you visited, named in lowercase with dashes (`seoul`, `busan`, `jeju`…), and upload the photos into it. Photos placed directly in this folder show as "Around South Korea".

On github.com: Add file → Upload files, then drag in a whole folder (for example a folder `seoul` with the photos inside).

Naming, sizes and privacy tips: see [the photos guide](../README.md).
