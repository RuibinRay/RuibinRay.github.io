# Photos from Canada

Make a folder here for each city or province you visited, named in lowercase with dashes (`toronto`, `vancouver`, `british-columbia`…), and upload the photos into it. Photos placed directly in this folder show as "Around Canada".

On github.com: Add file → Upload files, then drag in a whole folder (for example a folder `toronto` with the photos inside).

Naming, sizes and privacy tips: see [the photos guide](../README.md).
